# 文字化けで文字化けじゃない？

入力した日本語のうち、決められたひらがな・記号だけを特殊な文字列に変換する、ブラウザだけで動くWebアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「① もじを いれる」に文字を入力します。
3. 入力すると自動で「② へんかん けっか」に変換結果が表示されます。
4. 「へんかん！」でも変換できます。
5. 「コピー」で結果をコピーできます。
6. 「けす」で入力と結果を消せます。
7. 「れいをいれる」で `こんにちは！` の例を試せます。
8. 右上の「ダーク / ライト」で表示テーマを切り替えられます。

## 特徴

- HTML / CSS / JavaScript だけで動作
- Python不要
- 外部サーバー不要
- 入力中のリアルタイム変換
- 対応表にない文字は、そのまま出力
- 漢字・カタカナ・英数字も、対応表にない限りそのまま出力
- スマホ対応
- 小さな子どもでも押しやすい大きなボタンと文字
- ダークモード対応
- 外部ライブラリ、外部フォント、外部APIを使用しない
- 入力内容を外部へ送信しない

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。
2. このフォルダ内の次の5ファイルをリポジトリ直下にアップロードします。
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - `LICENSE`
3. GitHubのリポジトリ画面で **Settings** を開きます。
4. 左側の **Pages** を開きます。
5. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
6. Branchを `main`、フォルダを `/(root)` にして **Save** を押します。
7. しばらくすると、GitHub Pagesの公開URLが表示されます。

このアプリは相対パスで `style.css` と `script.js` を読み込むため、GitHub Pagesでもそのまま動作します。
